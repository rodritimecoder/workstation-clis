# Closed node types and status values

Only these card types exist in this map:

- `type: object` — one noun (class, table, durable file). Template: [../../../assets/templates/object.md](../../../assets/templates/object.md)
- `type: process` — one repeated movement. Template: [../../../assets/templates/process.md](../../../assets/templates/process.md)

`effects/` holds a catalog, not cards. Do not invent new types.

## Status values

- `illustrative` — this example's only status. The subject codebase does not exist; citations demonstrate format.
- `stub` / `stale` / `verified` — reserved for real maps. `verified` requires a date **and** a branch or commit plus citations; a confident wrong date is worse than none.
